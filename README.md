# LookupLab Excel Practice Dataset

Free, openly-licensed Excel practice workbook: **30 exercises across 6 function families** (Lookup, Logic, Aggregation, Text, Date, Dynamic Arrays), with a separate answer key. Every exercise pairs a realistic business scenario with a target formula and the expected result.

- **License:** CC BY 4.0 - reuse in courses, worksheets, and training material with attribution.
- - **Interactive companion:** https://formulalab.dev/practice.html - edit cells in a live browser spreadsheet, get instant feedback, no signup.
  - - **Function references:** https://formulalab.dev/ - 63 documented Excel functions with live examples.
